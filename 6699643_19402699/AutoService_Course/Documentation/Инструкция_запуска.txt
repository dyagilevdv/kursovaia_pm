ИНФОРМАЦИОННАЯ СИСТЕМА АВТОСЕРВИСА
ИНСТРУКЦИЯ ПО УСТАНОВКЕ И ПРОВЕРКЕ

1. Требования
- Windows 10/11.
- Visual Studio 2022 с компонентом «Разработка классических приложений .NET».
- .NET Framework 4.8 Developer Pack.
- SQL Server Express, Developer либо LocalDB.
- SQL Server Management Studio (для выполнения SQL-скриптов).

2. Развертывание базы
Откройте SSMS и подключитесь к своему экземпляру SQL Server.
Выполните Database/01_create_database.sql.
Проверьте, что появилась база db_autoservice и 15 таблиц.
Для демонстрации работы на пустой учебной базе выполните
Database/02_demo_data.sql. На рабочей базе предприятия это делать не нужно.

3. Подключение проекта
Откройте AutoService.sln. В AutoService.Wpf/App.config укажите имя сервера.
Пример для LocalDB:
    Data Source=(localdb)\MSSQLLocalDB
Пример для SQL Express:
    Data Source=.\SQLEXPRESS
Имя базы оставьте db_autoservice.
В примерах применяется интегрированная аутентификация Windows.

4. Сборка и запуск
Назначьте AutoService.Wpf запускаемым проектом, выполните «Собрать решение».
Для запуска нажмите F5. Должно открыться окно с разделом заказов.

5. Демонстрация
Откройте последовательно: «Заказы», «Автомобили», «Клиенты»,
«Услуги», «Запчасти». Проверьте поиск.
Добавьте услугу, измените ее стоимость, обновите список.
Добавьте клиента, затем автомобиль с выбором владельца.
Создайте заказ и выберите связанные значения из справочников.
Попробуйте сохранить пустое обязательное поле - появится предупреждение.
Попробуйте удалить услугу, уже связанную с заказом - SQL Server сохранит
целостность данных и программа покажет сообщение об ошибке.

6. Если не подключается
- Проверьте, запущена ли служба SQL Server.
- Проверьте точное имя экземпляра и совпадение имени базы.
- Проверьте доступ текущей учетной записи Windows к базе.
- Убедитесь, что команды из 01_create_database.sql выполнены без ошибок.

7. Скриншоты для защиты
Реальные скриншоты WPF можно получить только после запуска на Windows.
Подробный список рекомендуемых изображений приведен в приложении В
пояснительной записки.

Примечание. В среде подготовки архива отсутствовали Windows, компилятор
WPF и работающий MS SQL Server. Проведена структурная проверка исходников,
но запуск, компиляция Visual Studio и работа с реальной БД требуют проверки
на целевом компьютере. В приложении нет авторизации по полю Users.password.
