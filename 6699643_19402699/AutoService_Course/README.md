# Информационная система автосервиса

Настольное приложение для Windows на C# WPF (.NET Framework 4.8), работающее с существующей базой данных `db_autoservice` в Microsoft SQL Server.

## Состав поставки

- `AutoService.sln` - решение Visual Studio.
- `AutoService.Wpf/` - исходные коды WPF и ADO.NET.
- `Database/01_create_database.sql` - создание исходной структуры БД без путей чужого компьютера.
- `Database/02_demo_data.sql` - необязательные демонстрационные записи.
- `Documentation/` - пояснительная записка и инструкция по запуску.

## Как запустить

1. Установить Visual Studio 2022 с нагрузкой «Разработка классических приложений .NET» и пакет разработчика .NET Framework 4.8.
2. Установить SQL Server (Express, Developer или LocalDB) и SQL Server Management Studio.
3. В SSMS подключиться к нужному экземпляру и выполнить сначала `Database/01_create_database.sql`, затем при необходимости `Database/02_demo_data.sql`.
4. Изменить `AutoService.Wpf/App.config`: параметр `Data Source` должен указывать на установленный экземпляр SQL Server.
5. Открыть `AutoService.sln`, собрать и запустить проект (F5).

Необходима ОС Windows. На компьютере, где готовились исходные файлы, запуск WPF и проверка подключения к реальному SQL Server не выполнялись; в пояснительной записке приведены сценарии ручной проверки.

## Функции

- Просмотр и поиск заказов, автомобилей, клиентов, услуг и запчастей.
- Добавление и редактирование записей со списками связанных справочников.
- Удаление записей с подтверждением и обработкой ограничений внешних ключей.
- Проверка обязательных полей, чисел и дат; параметризованные запросы.

Исходные названия таблиц и полей сохранены, включая `Zakaz`, `Work_price`, `Zapchasti` и поле `id_town` типа `nvarchar(50)`.
